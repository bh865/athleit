Your coach or team admin gives you a **team code** or an **invite link**. Either way, a team staff member approves you before you can see anything.

## With a team code

<Steps>

1. Open **Join a team** in the app.
2. Enter the **Team code**.
3. Choose **Which child is this for?** If your child is not listed, [add your child to your family first](/help/a/link-your-child-to-your-family).
4. Add an optional message for the coach, then choose **Send request**.

</Steps>

The request goes to the team's staff. You get access once they approve it.

<Callout kind="note">
  Sending a request does not give you access to the roster or messages. Until staff approve it, you
  see only that the request was sent.
</Callout>

## With an invite link

Open the link and follow the steps. Some links are made for a parent, some for a coach or manager. If the link does not match your role, ask the person who sent it for a new one.

## Who can approve and share codes

<WhoCanDo capability="joinRequests.decide" label="Approve join requests" />

<FAQ>
  <Q q="My request is still waiting.">
    Staff approve requests by hand. Ask your coach to check the team's join requests.
  </Q>
  <Q q="The code says it is not valid.">
    Check for typos, then ask a team admin for the current code. Team admins can change the code at
    any time, which stops the old one working.
  </Q>
</FAQ>
